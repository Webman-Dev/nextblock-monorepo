# Brand Guidelines

## 1. Design Language & Aesthetic

**Theme:** Dark Mode Default.
**Background:** Deep slate gray / near-black (e.g., `#111827`).
**Typography:** [Inter](https://rsms.me/inter/) variable font. Clean, highly legible sans-serif.

### Color Palette

- **Primary Text:** Light gray / off-white (`#F3F4F6` or similar).
- **Accents:** Vibrant Blue-to-Purple Gradient.
  - **Start:** `#3B82F6` (Blue 500)
  - **End:** `#8B5CF6` (Violet 500)
  - **Usage:** Buttons, link underlines, icon highlights.

### Layout Principles

- **Spacious:** Generous whitespace between sections.
- **Clean:** Single-column flow for main content.
- **Subtle Motion:** Gentle fade-ins and smooth hover transitions.
